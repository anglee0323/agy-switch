## 本次更新

- 配额查询改用 Antigravity 客户端实际使用的 `daily-cloudcode-pa.googleapis.com` 优先，沙箱和生产端点作为回退。只返回 Claude/GPT 组的 HTTP 200 响应仅作部分兜底，不再与其它端点环境的数据合并成一份完整观测。
- 请求 User-Agent 改为 `antigravity/hub/<版本> (os_type=…; arch=…)`。服务端不再按旧客户端降级，Gemini 4 Argon、Hydrogen、Carbon 的模型列表和第三个配额组（Gemini 4 Argon 周额度）会正常返回。
- 模型目录新增 Gemini 4 Argon（Low/Medium/High），Orchestrator (Argon) 与 Orchestrator (Carbon) 归到对应模型的额度；`-disabled` 模型显示「—」，不再借用共享池百分比。
- 修正 5 小时与周配额的取值：模型上报的 `primary_quota` 若对应周桶的重置时间，5H 视图不再把它当成 5 小时额度，避免显示错误的百分比和倒计时。5H 视图只显示五小时额度，周配额视图只显示周额度。
- 修复「周期变化」弹窗：前端读取的字段与后端返回不一致，弹窗此前一直为空。现在按账号分组显示周期记录、检查点、消耗金额和环比。
- 估值校准增加保护：冷启动和离群样本不再写入参考上限，异常环比不再显示。

## Changes

- Queries `daily-cloudcode-pa.googleapis.com` first, matching the Antigravity client, with the sandbox and production endpoints as fallbacks. An HTTP 200 that only contains the Claude/GPT group is kept as a partial fallback instead of being merged with another endpoint environment.
- Sends the `antigravity/hub/<version> (os_type=…; arch=…)` User-Agent, so the server no longer downgrades the response. Gemini 4 Argon, Hydrogen and Carbon models and the third quota group (Gemini 4 Argon weekly) are reported again.
- Adds Gemini 4 Argon (Low/Medium/High) to the model catalog and maps Orchestrator (Argon) / Orchestrator (Carbon) to their model's allowance. `-disabled` models show an unknown value instead of borrowing the shared pool percentage.
- Fixes the five-hour and weekly readings: when a model's `primary_quota` matches the weekly bucket's reset time, the 5H view no longer presents it as a five-hour allowance, which previously showed a wrong percentage and countdown. The 5H view shows only the five-hour allowance and the weekly view only the weekly allowance.
- Fixes the cycle-history dialog, which stayed empty because the frontend read a different response shape than the backend returns. It now lists cycles, checkpoints, consumed cost and the cycle-over-cycle change per account.
- Guards valuation calibration: cold-start and outlier samples no longer become reference caps, and implausible cycle-over-cycle changes are not displayed.

## Verification and limits

Rust unit tests (261 passed, 4 ignored), the shared quota/pricing/catalog fixtures, the frontend build and the mocked UI suite (153 passed) cover this change, together with the three platform package jobs. The contributor verified quota refresh and model display on Windows 11 with real accounts; this release does not change account data or credentials. No real account was switched, refreshed, exported or deleted during maintainer verification, and the macOS tray and installed-package behavior were not exercised with a signed-in account. Mac packages still lack Developer ID/notarization and Windows packages lack Authenticode; bundle and updater signatures do not establish OS trust. Installation requires user action; see [updates](../software-updates.md).
