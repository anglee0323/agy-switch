## 本次更新

- 单个和批量账号导出的 JSON 文件名加入本机日期与时间，精确到秒，便于区分多次备份。
- 数据目录按钮改为“在文件夹中打开”，适用于 macOS、Windows 和 Linux。
- 修复部分账号导入成功后，取消和确认按钮无法关闭弹窗的问题。确认已完成的导入只关闭结果，不会重复导入；手动关闭后清理旧计时器，避免误关重新打开的弹窗。
- 统一账号套餐筛选、数量统计和列表／卡片徽章。缺失或空白的套餐信息显示为“待识别”，支持单独筛选，刷新取得套餐后自动归类；每个账号只属于一个分类。

## Changes

- Single-account and selected-account JSON exports suggest filenames with the local date and time to the second, making repeated backups easier to identify.
- The data-directory button now uses the platform-neutral “Open folder” label on macOS, Windows and Linux.
- Cancel and Confirm can close completed or partially successful account imports. Confirm acknowledges the result without importing again. Closing the dialog clears its previous delayed-close timer so it cannot close a reopened dialog.
- Account plan filters, counts and list/card badges share one classifier. Missing or blank plan observations appear as Unknown with a dedicated filter, and a later quota refresh can move them to their reported plan. Each account belongs to exactly one category.

## Verification and limits

Both feature PRs passed three-platform Build checks and both optimized CLI checks. The combined feature source also passed its final main CI. Local frontend builds, 17 scoped synthetic account/import/transfer/layout UI tests, six transfer parsing checks and ten Settings component-contract checks passed. Regressions cover both dialog buttons, partial and complete import results, stale close timers, OAuth completion with missing plan information, reload, later quota refresh and bilingual list/card presentation.

These checks use synthetic accounts and mocked service responses. No maintainer account was authorized, switched, refreshed, deleted, exported or imported to test these changes. A missing plan observation is not evidence of a Free subscription; All = Pro + Ultra + Free + Unknown. OAuth already attempts quota discovery, but network failures and incomplete responses can leave a plan unknown until a later refresh.

The release workflow additionally validates the actual package set, Windows/Linux installation and terminal behavior before publication. Native Homebrew installation, upgrade, custom app directory and uninstall acceptance remain separate tasks. Account-page switching still synchronizes App and an initialized native agy CLI session; explicit IDE switching and backend safeguards remain available. Existing agy processes may retain an old session until restarted, and saved selections are not proof of live credentials.

本次修复没有改变真实授权、账号切换、系统代理或凭据存储逻辑。安装仍需用户操作；没有提供强制或完全无人值守的更新。

Mac packages have no Apple Developer ID/notarization; Windows packages have no Authenticode certificate. Complete ad-hoc bundle integrity and updater signatures do not establish OS trust.
