## 本次更新

- 设置末尾新增“实验功能”。macOS 用户可以一键应用 Antigravity 推荐配置，也可以逐项调整执行权限、计划审批、项目外访问、网页读取、浏览器操作、追问发送、对话宽度、思考显示、AI Credits、防止休眠和后台运行。
- 懒人配置同时配置 Antigravity App 与 agy CLI；防止休眠和后台运行是 App 设置。Codex、Claude Code、Pi Agent 不受影响。修改后仅显示“已自定义”；重新选择推荐配置会再次应用默认值。
- 权限规则支持 JSON 编辑，区分网页读取与浏览器操作，保留现有规则、插件、Hooks 和客户端迁移标记。设置通过客户端原生接口部分更新，并重新读取确认。
- 新增可关闭的 App 汉化，覆盖侧边栏、设置及嵌套权限页面、内置自定义、历史和自动化页面的已知界面文字。关闭后恢复原文。按控件与页面结构识别布局，不依赖侧栏列数。
- 智能切换的等待模式读取实时任务和执行器状态，确认空闲后才尝试关闭客户端，并在关闭前再次检查。移除通过对话文件更新时间推断结束的逻辑；任务状态未知时继续等待，无需额外 Hook 或通知。

## Changes

- Adds Experimental Features at the end of Settings. macOS users can apply Antigravity's recommended setup or adjust execution permissions, plan review, outside-project access, web reading, browser actions, follow-up delivery, conversation width, thinking visibility, AI Credits, sleep prevention and background operation.
- Shared setup configures both Antigravity App and agy CLI; sleep prevention and background operation are App preferences. Codex, Claude Code and Pi Agent are unaffected. Edits show Customized, and choosing Recommended again reapplies the defaults.
- Adds a JSON permission-rule editor with separate web-reading and browser-action rules. Partial native writes preserve existing rules, plugins, Hooks and migration markers and reread saved values for confirmation.
- Adds reversible App translation for known built-in sidebar, settings, nested permission, customization, history and automation labels. Scopes use controls and page structure rather than sidebar column positions.
- Wait-mode smart switching reads live conversation/executor state and checks again before attempting to close clients. Transcript modification time is no longer treated as completion evidence. Unknown state keeps switching pending, without an extra Hook or notification.

## Verification and compatibility

Live macOS acceptance used Antigravity App 2.21.1: native sleep preferences were changed and restored, shared display preferences were changed and restored, and a same-value plan setting was confirmed through the real native API. Sidebar, General and nested permission pages, Application, Appearance, Models, customization list/detail controls and translation restoration were inspected in the actual App. The fixture used isolated Switch storage, did not switch accounts and did not modify permission policies. Read-only trajectory/executor observations were checked separately from switching.

Experimental settings/translation currently support only the macOS standalone App. Older sidebar structures have synthetic fixture coverage, not full native version-by-version acceptance. Unknown future labels retain their original text. Translation requires AntiGravity Switch to keep running; a 15-second lease restores the original text when renewal stops. Chats, code, user input, project names, plugin Readmes, embedded third-party pages and the OS menu bar retain their original content. Dictionary entries include MIT-licensed EasyAntigravity material with bundled attribution.

Live task confirmation currently supports the macOS standalone App. Running agy CLI/IDE executors, additional language servers, Windows/Linux and unavailable observations remain unknown and keep wait mode pending. Threshold mode still explicitly permits interrupting running work. A process observation cannot prevent new work starting immediately afterward; this change does not provide atomic task migration or authenticated native account-switch acceptance.

Source regression tests cover partial settings validation, process/listener/target ownership, bounded transport responses, preset/custom transitions, JSON editing, failed writes, translated dynamic pages, content exclusion, restoration and wait-mode rechecks. The final release workflow requires all three platform packages, isolated packaged CLI/installer checks, complete asset hashes and the signed update feed before publication. Browser/synthetic checks are distinct from actual client acceptance.
