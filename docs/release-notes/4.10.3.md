## 本次更新

- 默认切号同步 Antigravity App 与已初始化的原生 agy CLI；账号页可单独选择 IDE，IDE 换号只更新其数据库并重启正在运行的 IDE。两端分别记录当前账号，CLI 支持 `current --target app|ide` 查询。新建自动切换策略默认 App/CLI，已有明确选择的全域策略保留原范围。
- 网络代理默认跟随系统固定代理及代理环境变量，支持 macOS、Windows、GNOME/KDE 的常见 HTTP/SOCKS 设置；运行期间重新读取。也可在设置中选择手动代理或直连。Refresh Token 导入、授权和额度请求不再要求开启 TUN。PAC 脚本需改用代理工具的本地 HTTP/SOCKS 地址。
- 恢复单个账号和批量选中账号的 JSON 导出，并支持选择文件导入。导出保留 OAuth 客户端、项目、名称与备注，兼容旧版 token-only JSON；不包含访问令牌、设备信息或额度缓存。导出文件含登录凭据，请妥善保管。
- 本地导入分别扫描 App、CLI、IDE 和插件，支持更多 IDE 目录命名和自定义数据路径。修复 IDE 错用 App 钥匙串、首次导入失败后跳过重复来源，以及新版数据库记录损坏导致旧版有效记录被忽略的问题。导入结果显示失败来源，可重试或关闭。
- App 与 IDE 的启动参数和设备数据同步分别处理；当两端使用同一数据库时，在关闭客户端前提示设置独立数据目录，避免独立切号误改另一端。

## Changes

- Manual switching synchronizes Antigravity App and an initialized native agy CLI session by default. The account page can switch IDE independently, updating only its databases and restarting only a running IDE. Each client has a separate recorded selection, available through `current --target app|ide`. New scheduler policies default to App/CLI; existing explicit global policies retain their scope.
- Networking follows fixed system proxies and proxy environment variables by default, including common macOS, Windows and GNOME/KDE HTTP/SOCKS settings, reread during operation. Settings provide manual proxy and direct modes. Refresh-token import, authorization and quota requests can use a fixed proxy without TUN. PAC scripts require the proxy tool's local HTTP/SOCKS address.
- Restores single-account and selected-account JSON export and file import. Exports preserve OAuth client/profile, project, name and remark metadata and accept older token-only JSON on restore. Access tokens, device data and quota caches are excluded. Export files contain login credentials and must be kept private.
- Local import discovers App, CLI, IDE and plugin sources independently, including additional IDE directory names and custom data paths. Fixes App keyring fallback hiding IDE credentials, failed attempts suppressing later sources, and corrupt newer database records preventing valid legacy fallback. Failed sources remain visible and can be retried.
- Separates App/IDE launch arguments and device-data writes. Independent switching rejects a shared client database before shutting down either client.

## Verification and limits

Local frontend build, locked Rust checks, isolated production storage/selection/import/export tests, HTTP and SOCKS forwarding tests, runtime proxy-change checks, 42 CLI smoke checks and 68 real PTY checks passed. Mocked UI acceptance covers switch targets, exports, JSON restore, partial import failures and network settings; existing scheduler/settings/quota UI regressions also passed.

These tests use synthetic accounts, temporary databases and a mock credential-store callback. They do not establish live Google login, real App/CLI/IDE account switching or every user's proxy configuration. Existing long-running agy commands may retain the old session; start a new invocation after switching. Saved selections are local records rather than proof of live identity. PAC evaluation and automatic proxy discovery remain unsupported.

本次未对维护者的真实账号执行切号、刷新、导出或导入。安装包与 CLI 的跨平台验证由发布流程执行；真实登录、用户代理环境和物理托盘仍需对应平台验收。
