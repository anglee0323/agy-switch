## 本次更新

- 修复从菜单栏打开首页、账号管理或设置时，窗口红绿灯按钮先出现、页面随后弹出的显示顺序问题。目标页面提交后再显示完整窗口，主窗口使用不透明背景；后台启动保持隐藏，连续点击保留最新请求，关窗后的旧请求不会再次弹出窗口。
- 网络代理设置自动生效，移除保存按钮。跟随系统和直连立即应用；有效手动地址在输入暂停、离开输入框或按回车后应用，无效地址保留上一份有效设置。
- 首页每分钟扫描本地用量，回到窗口时立即重扫，并分别显示扫描时间和最新用量记录时间。后台命令仍在运行，并不代表 Antigravity 已写入新的模型用量记录。
- Gemini 同版本、同基础型号的推理档位和内部实验后缀按基础型号估算费用，覆盖 High、单字母后缀和 exp／test／preview 等形式。精确价格优先；不同版本、Flash Lite、图像／音频等产品变体保持独立，未知或冲突价格仍显示未计价。首页、原生菜单与 CLI 使用一致规则。
- 更新中英文使用说明、源码构建指南和维护规范。开发构建可能保留当前公开版本号，需通过源码提交和安装包内容确认实际更新。

## Changes

- Menu actions commit the requested Dashboard, Accounts or Settings page before revealing an opaque main window. This fixes the window controls appearing ahead of the page. Background startup remains hidden; repeated requests keep the latest destination, and closing cancels pending reveals.
- Proxy settings apply automatically without a Save button. System and direct modes apply immediately; a valid manual address applies after a typing pause, blur or Enter. Invalid addresses preserve the last valid routing configuration.
- The Dashboard scans local usage every minute and on returning to the window, displaying scan time separately from the newest recorded usage. A running background command alone does not create new model-token records.
- Gemini thinking levels and internal experiment suffixes use the same version and basic model's estimated rate, including High, single-letter suffixes and exp/test/preview forms. Exact catalog entries take priority. Other versions, Flash Lite and image/audio product variants stay separate; unknown or conflicting rates remain unpriced. Dashboard, native menu and CLI matching agree.
- English/Chinese guides and maintainer rules now document current behavior, source builds and installed-payload verification. Development builds can retain the current public version metadata, so a version string alone does not establish code provenance.

## Verification and limits

Included fixes passed three-platform source builds, full synthetic UI regression, Windows/Linux native window and lifecycle checks, both optimized CLI jobs, and three-platform package candidates. Locally, the window fix passed the frontend production build, a locked Rust check, 10 desktop tests, 16 isolated AppKit lifecycle stages and 17 scoped UI cases. Its full local UI run passed 115 cases with one existing English card assertion timing out; both locales passed a focused rerun. The full CI UI run passed. Shared Gemini alias fixtures cover 35 cases in TypeScript and Rust.

The verified local ARM64 source build passed complete resource-signature and empty-entitlement checks; both executable entries and the installed console passed 42 isolated CLI checks. Native reopening rendered the complete Dashboard, and saved preferences remained unchanged. These checks validate ordering and visibility, not a measured first-pixel latency or every physical menu-click scenario. No real account was switched, refreshed, imported, exported or deleted for verification, and no Antigravity task was stopped.

The release workflow validates the final version's complete packages, actual Windows/Linux installation and terminal behavior before publication. Public package verification is recorded afterward in the maintainer acceptance guide. Native Homebrew installation, upgrade, custom app directory and uninstall acceptance remain separate. Proxy support includes fixed system proxies and environment variables; PAC evaluation and automatic proxy discovery remain unsupported. API costs are estimates, and unknown rates stay unpriced.
