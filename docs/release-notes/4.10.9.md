## Changes

- Correct effective quota after 4.10.8: model availability is bounded by both the five-hour and weekly windows. An exhausted week cannot look 100% available, and reset times follow the limiting window. A shared summary cannot increase a lower primary model observation. CLI and automatic switching use the same limits; menu/tray window rows retain their individual source values.
- Make Gemini 4 Argon selectable independently of catalog availability. Use a reported dedicated weekly pool, otherwise show unknown. Retain catalog models without quotaInfo and their metadata. Selecting or refreshing a model does not grant access.
- Prefer production quota/catalog endpoints and fall back from permission failures or malformed/empty summaries. Recheck subscription tiers on refresh; fix isDefault parsing and stale Free labels after plan changes.
- Accept JSON exports through the local file picker, validate credentials with the exported OAuth client, validate the batch before importing, and keep partial-failure counts visible.
- Include the independently running macOS App Hub in manual switch shutdown/restart so an old cached session cannot survive the App window. Unverified ownership or a failed close blocks credential writes.

Includes the contribution from PR #83 and addresses issue #84.

## Verification and limits

Regression coverage includes quota exhaustion and reset selection, independent
Argon pools, conflicting/unknown observations, subscription parsing, local HTTP
permission/fallback fixtures, JSON metadata/validation, partial import UI, and
manual Hub ordering/failure handling. Backend tests use synthetic data and local
listeners. Browser tests cover Chinese/English account cards and tables.
Three-platform source and candidate-package checks are required before tagging;
release packaging checks the actual installers, terminal programs and asset set.

The feedback screenshot does not identify the failing OS or App/IDE version.
Hub handling fixes an identified macOS path; it does not prove the screenshot's
original authenticated switching failure has been reproduced or that every
client version is compatible. No real saved accounts or OS credentials are
switched/refreshed during acceptance. Live entitled Argon behavior remains
unverified when the upstream API omits that pool. See [quota limits](../quota-pools.md)
and [account scopes](../account-scopes.md).

Mac packages lack Developer ID/notarization and Windows packages lack Authenticode.
Bundle integrity and updater signatures do not establish OS trust. Installation
requires user action; see [updates](../software-updates.md).
