## Changes

- The macOS app, Dock name, native menu header and tray tooltip consistently display **AntiGravity Switch**. The manual-install ZIP contains `AntiGravity Switch.app`; the terminal command remains `agy-switch`.
- The English and Chinese guides now start with supported clients and visible interface examples, followed by installation and everyday operations. Each guide includes six visible screenshots: dashboard, menu bar, account list, account cards, settings and terminal.
- Release downloads focus on the three desktop packages and two console packages. Package hashes remain in `release-manifest.json`, and update signatures remain in `latest.json`; redundant sidecar attachments are kept in CI rather than the public download list.
- The unused local deploy helper is removed; it could match unrelated processes and replace only part of an app bundle.
- Obsolete design drafts, local preview journals and superseded screenshots are removed. Maintainer contracts and validation procedures are grouped separately from user guides.

## Updates and platform limits

With **Check for updates on startup** enabled, the app checks after startup and displays a new-version prompt. Choose **Download and install** to download and verify the update. A dismissed version remains available through the manual check in Settings. The 4.9.0 Mac updater archive layout is preserved so an already installed branded app can read the new package.

The release workflow verifies all three platform packages, their exact checksums, the Homebrew recipe and the signed update feed before publication. Windows tests include per-user installer and PowerShell/ConPTY checks; Linux tests include APT installation and PTY checks. Native-window checks use isolated synthetic accounts and are separate from real Google authorization and authenticated account switching. No screenshot demonstration data is included in the production build.

These packages have no Apple Developer ID/notarization or Windows Authenticode certificate. macOS validates Gatekeeper before replacing the app and preserves the current installation when trust checks fail. Fully unattended Mac installation is therefore unavailable. Windows security prompts and Linux installation authentication may appear. Homebrew does not bypass platform trust; its matching recipe is updated after the public ZIP is verified.
