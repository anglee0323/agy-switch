## Changes

- The application displays **AntiGravity Switch**. The repository, packages and management command use **agy-switch**. App icons use the selected spectral twin-wave artwork; the Mac menu bar uses a larger monochrome twin-wave template.
- The CLI now supports smart-switch policy settings, account and candidate ordering, and update checks. Terminal navigation consistently uses arrow keys, Enter and Escape while retaining numeric shortcuts.
- Smart-switch settings distinguish **Switch timing** from **Account selection order**. The CLI and desktop app share the saved policy; the background scheduler remains a desktop feature.
- Google pricing parsing now includes numbered Standard sections. Existing price caches refresh when the parser revision changes. The explicit Gemini 3.8 Flash EXP-A alias uses the corresponding Flash estimate; other model versions are not silently substituted. CLI aggregate costs no longer append a partial-estimate suffix, while unpriced model rows remain explicit.
- English and Simplified Chinese documentation describes desktop and CLI installation separately for macOS, Windows and Linux.

## Validation and limits

Local Apple Silicon validation includes the installed optimized Mac app, its full display name and selected logo, strict bundle signature integrity, frontend production builds, branding contracts, 138 passing Rust library tests (2 platform-specific helper cases ignored), pricing checks and real terminal policy/order interaction checks. The final PR and tagged release workflows separately build and test Windows/Linux packages and release console binaries. Their source-specific acceptance records distinguish native window tests from package installation tests.

The app and CLI share account data and policy settings. Linux provides a Debian desktop package and a separate console tarball; its console executable still requires GTK3, WebKitGTK 4.1 and AppIndicator runtime libraries. Windows provides a per-user x64 installer and a separate console ZIP. Linux desktop tray support and Wayland placement depend on the desktop environment. Physical Windows/Linux devices, live Google authorization and authenticated account switching are not established by synthetic hosted-runner tests.

Update-package signatures are independent of OS code signing. These builds have no Apple Developer ID/notarization or Windows Authenticode certificate. The Mac updater checks Gatekeeper before replacing the app and preserves the current app if the new bundle is untrusted. Windows security prompts and Linux installation authentication may appear. Fully unattended Mac installation is not claimed.

Older Tools Lite releases retain their immutable files and checksums. Existing data paths and the bundle identifier are unchanged; old command-name aliases are not provided. Because the previous updater pinned the old repository URL, its first branded upgrade may require manual installation or Homebrew. Homebrew's matching 4.9.0 recipe follows verification of the actual public Mac ZIP; do not install the old and new casks side by side. A downloaded checksum or valid updater signature does not bypass platform trust.
