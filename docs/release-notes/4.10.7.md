## Verification and limits

The merged cleanup passed three-platform source builds and both optimized CLI jobs. Its local audit reported a warning-free locked Rust check, 200 passing library tests with four ignored tests, the frontend production build and the affected Node regression suites. Final-version source and package checks run before publication, including isolated CLI, terminal and actual Windows/Linux installation checks. Public-package acceptance is recorded afterward in the maintainer guide; earlier release results do not substitute for final-version verification.

Tests use synthetic account storage. No real account switching, refresh, import, export or deletion is performed for acceptance, and no Antigravity task needs to be stopped. Local replacement and publication are separate operations; the installed package's source and bytes identify it. Window checks establish presentation ordering, not a measured first-pixel latency. Native Homebrew installation/upgrade/uninstall remains a separate acceptance scope.

Mac 安装包没有 Developer ID 签名或公证，Windows 安装包没有 Authenticode 证书。完整资源签名和更新签名不能替代操作系统信任；安装仍需用户操作。

Mac packages have no Apple Developer ID/notarization; Windows packages have no Authenticode certificate. Bundle integrity and updater signatures do not establish OS trust.
