## 本次更新

修复 Mac 仅保留菜单栏运行一段时间后，其他账号额度变为未知、只剩当前账号显示的问题。全部账号的自动额度刷新改由原生后台任务执行，主窗口隐藏时仍按设置运行，不再依赖隐藏网页的定时器。默认五分钟周期会提前安排刷新，降低缓存到期时的显示空档。

手动刷新与自动刷新共用正在进行的请求，避免重复刷新。关闭自动刷新或调整间隔后，后台任务遵循新的设置；已开始的请求会完成。失败或过期额度仍显示未知，不把旧缓存当作有效额度。

## Changes

Fixes other accounts becoming unknown in the Mac menu after the app runs with only its menu bar visible. Full-account quota refresh now runs in a native background task and follows the saved interval while the main window is hidden, independently of hidden webview timers. Refresh is scheduled slightly before the freshness deadline to reduce gaps.

Manual and automatic refresh share an in-flight batch instead of sending duplicate requests. Disabling automatic refresh or changing its interval takes effect in the native scheduler; an already started batch can finish. Failed or stale observations remain unknown.

## Verification and update limits

The feature source passed 156 Rust tests (two platform-specific tests ignored), 14 settings/background browser checks, ten component contract checks, frontend builds and locked Rust checks. The Apple Silicon source package passed isolated CLI and terminal tests. A read-only observation after more than five minutes with the main window hidden found fresh quotas for all five eligible accounts, without manually refreshing or switching accounts. The automation tool could inspect the main window but did not capture native menu updates directly; immediate visual behavior in that menu is not claimed as separately verified.

Publication is gated on the final version's three platform packages, package checksums and signed updater feed. Physical Windows/Linux desktop behavior, real Google login and authenticated account switching were not exercised for this change. Homebrew recipe checks are separate from native installation acceptance.

With startup update checks enabled, eligible installations discover the stable release and offer an update; Settings also provides a manual check. Packages have no Apple Developer ID/notarization or Windows Authenticode certificate. Mac installations that fail system trust checks use the release page for manual installation. Homebrew does not bypass platform trust, and fully unattended Mac updates are not provided.

开启启动时检查更新后，应用会检查稳定版本并提示更新，也可在设置中手动检查。当前 Mac 安装包仍无 Apple 开发者签名和公证，系统信任检查未通过时需通过发布页手动安装；不提供强制、实时或完全无人值守的更新。
