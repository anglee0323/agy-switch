## 本次更新

首页提供 10 张可选指标卡片，包括账号状态、综合额度和平均输入规模。设置中可独立选择显示内容并拖动排序；勾选或取消勾选保持选项位置，重新显示时沿用保存的顺序。正常桌面窗口每行最多 5 张卡片，10 张正好两行，所有卡片尺寸一致。短窗口可滚动查看模型明细，中英文说明更清晰。

综合额度以进度条显示 5 小时和周额度的平均使用比例，与菜单栏使用相同的统计范围及颜色阈值。账号状态区分可用、不可用和未知观测。平均输入规模根据所选日期范围的请求数及输入、缓存输入计算，替换参考意义有限的额度重置卡片。

首字延迟和正文速度汇总最近 7 天内最新 10 次有效文本回复，使用中位数并合并不同模型及本地桌面、CLI 记录。直接读取已有记录，不发送测速请求。缺少有效样本时显示未知。

Mac 菜单栏打开期间会跟随本地额度快照更新，其他账号的缓存额度无需关闭再打开才能显示。关闭菜单后停止该界面的更新任务。

## Changes

The Dashboard offers ten optional cards, including account status, aggregate quota and mean request input. Selection and full option order are stored separately: toggling does not move options, hidden cards remain sortable, and reselecting restores their saved position. Desktop windows at least 1024 pixels wide show at most five cards per row, so ten cards occupy exactly two equal-sized rows. Model details remain reachable in short windows, with clearer Chinese and English copy.

Quota progress bars show mean usage for the 5-hour and weekly windows using the menu's scope and remaining-quota color thresholds. Account status distinguishes available, unavailable and unknown observations. Mean request input pools input and cached-input tokens by request count within the selected date range, replacing the quota-reset card without enabling previously hidden cards.

First-text latency and body speed report medians of the latest ten eligible text replies within seven days across models and local desktop/CLI stores. They read existing records without sending benchmark prompts; missing samples remain unknown. The Mac quota menu follows local snapshots while open and stops its update worker when dismissed.

## Verification and update limits

The final feature source passed 37 synthetic browser checks across both languages and wide/narrow windows, frontend production builds, configuration persistence tests and isolated CLI checks. A local Apple Silicon source package was inspected in its native window for stable checkbox positions, saved selection and the ten-card 5+5 layout. These local checks precede the final versioned packages; the release workflow separately gates publication on all three package jobs, checksum verification and a signed updater feed. Physical Windows/Linux desktop behavior and real Google login or authenticated account switching were not exercised for this change.

With startup update checks enabled, eligible installations discover this stable release and offer an update; manual checks remain available in Settings. These packages have no Apple Developer ID/notarization or Windows Authenticode certificate. Mac installations that fail system trust checks open the release page for manual installation and preserve the current app. Homebrew does not bypass platform trust. This release does not provide forced or fully unattended Mac updates.

开启启动时检查更新后，应用会检查稳定版本并提示更新，也可在设置中手动检查。Mac 当前仍无 Apple 开发者签名和公证，未通过系统信任检查时打开发布页，需手动安装并保留原应用；不提供强制、实时或完全无人值守的更新。
