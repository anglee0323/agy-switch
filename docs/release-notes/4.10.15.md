## 本次更新

- 修复费用估算全部变成“未计价”的问题。Google 把 Gemini 定价页改成了新的模板格式，旧的表格解析拿不到任何价格，只能退回内置价目表。现在按官方发布的新格式解析，并改用 Anthropic 官方价格页作为 Claude 的价格来源；任一价格页解析不到模型时会明确提示，不再把内置价格当成刚解析到的官方价格。内置兜底价目表同时修正了 Gemini 3.6 Flash 与 3.5 Flash Lite 的单价。
- 账号卡片与列表新增配额价值折算：按已记录的用量和匹配到的模型价格，显示每个额度窗口已消耗与剩余金额（美元、人民币或双币对照）以及等效 Token 数量。估值按 Gemini、Claude/GPT、Gemini 4 Argon 三个池分别计算，不跨池混算；窗口消耗低于 3% 时不做总额外推；满额窗口使用自定义参考上限、历史校准中位数或内置套餐基准，并在行内标出来源。
- 新增“周期变化”入口：按账号查看各额度窗口在每个周期内的消耗、与上一周期的环比变化和窗口内的检查点记录。
- 修复账号卡片中长模型名与重置倒计时压住金额的问题：名称过长时省略，倒计时在窄卡片里换行显示。
- 新增 USD → CNY 汇率获取，默认每天自动更新一次并缓存 24 小时，也可固定为自定义汇率。

## Changes

- Fixes every cost estimate collapsing to "unpriced". Google replaced the Gemini pricing page with a new template format, so the old table parser found no rates and silently fell back to the built-in table. The app now parses the published format, uses Anthropic's official pricing page for Claude, and reports a warning when a page yields no model instead of presenting built-in rates as freshly parsed official ones. The built-in fallback table also corrects the Gemini 3.6 Flash and 3.5 Flash Lite rates.
- Account cards and the account table can now show a quota's API-equivalent value: consumed and remaining amounts per window in USD, CNY or both, plus token equivalents, derived from recorded usage and matched model prices. Each pool (Gemini, Claude/GPT, Gemini 4 Argon) is valued separately, windows below 3% consumption are not extrapolated, and a full window uses a user reference cap, a calibrated median or the built-in plan baseline with its source labelled in the row.
- Adds a **Cycle Delta** entry per account: consumption per quota window for each cycle, the change against the previous cycle of the same bucket, and the checkpoints recorded while the window was open.
- Fixes long model names and reset countdowns overlapping the amounts in account cards: names ellipsize and the countdown wraps in a narrow card.
- Adds a USD → CNY rate that refreshes once a day and is cached for 24 hours, or a fixed user rate.

## Verification and limits

The pricing parser was checked against the live pages on 2026-11-09: 29 Gemini and
15 Claude models parsed, including `gemini-3.8-flash` at $0.75 input / $3.75 output
/ $0.075 cached per 1M tokens, which is the model reported as unpriced in #129.
A page that returns no model now produces a warning and marks the snapshot stale.
Image-only models still price their per-image output line as a token rate; they are
not used by the local token records this estimate reads.

Quota valuation is an estimate of commercial value, not a subscription bill. It is
desktop-only; the terminal dashboard keeps reporting percentages. Calibration and
reference baselines are synthetic-data verified, not reconciled against a real
invoice. The three local state files (`account_usage_spans.json`,
`quota_capacity_calibration.json`, `quota_cycle_history.json`) are capped at 35 days,
9 samples and 24 cycles per bucket.

Rust tests (253 on macOS), 153 mocked UI checks, the script suites and the three
package jobs passed in CI. No real account was switched, refreshed, exported or
deleted for these checks.

Mac packages lack Developer ID/notarization and Windows packages lack Authenticode.
Integrity and updater signatures do not establish OS trust. Installation requires
user action; see [updates](../software-updates.md).
