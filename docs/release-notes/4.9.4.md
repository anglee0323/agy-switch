## 本次更新

- 修复官方 Antigravity 客户端更新后，Mac 菜单无法识别当前登录账号的问题。身份检测不再限定客户端的精确版本；无法验证登录状态时明确显示检测中或未知。
- 修复“仅在菜单栏显示”模式下，打开并关闭主窗口后 Dock 图标仍然保留的问题。启动、显示和关闭窗口时会重新应用最新设置；普通设置保存也不会覆盖较新的桌面或菜单偏好。
- 当前账号记录同步改由原生后台任务执行，主窗口隐藏时仍按设置运行，并合并重复请求。日志区分实际自动切换与登录记录校准；校准记录不代表执行了账号切换。
- Windows/Linux 托盘区分保存的账号选择与已验证登录，统一账号排序、切换资格和额度有效性。修复 Windows 面板阴影超出屏幕工作区、Linux 后台启动露出主窗口和后台显示器查询导致退出的问题。
- 没有可用托盘时，关闭主窗口会退出应用，避免留下无法重新打开的后台进程。

## Changes

- Fixes the Mac menu losing the current login after the official Antigravity client updates. Identity detection no longer requires one exact client version; checking and unverified states are explicit.
- Fixes the Dock icon remaining after opening and closing the main window in menu-only mode. Startup, show and close reconcile the latest preference, and ordinary settings saves preserve newer desktop/menu preferences.
- Moves selected-account synchronization to the native scheduler so it follows saved settings while the main window is hidden and coalesces duplicate work. Diagnostics distinguish an actual automatic switch from correcting a saved login record; record correction does not perform an account switch.
- Aligns Windows/Linux tray ordering, switch eligibility and quota freshness, while distinguishing a saved selection from verified login. Fixes Windows panel shadows extending outside the work area, Linux background startup showing the main window, and Linux exiting after monitor queries from a background task.
- Closing the main window without a usable tray exits the app instead of leaving an inaccessible background process.

## Verification and update limits

The [feature source](https://github.com/anglee0323/agy-switch/pull/46) at `732c89d8ca3313c5a937327c4f5d041ac29b2435` passed 12 macOS native lifecycle stages, 16 Windows and 16 Linux native lifecycle stages, and seven actual native WebView captures on each of Windows/Linux. These cover Dock policy reconciliation, repeated panel opens, native frame bounds, close/blur, no-tray recovery and clean exit. WebView checks cover real Rust IPC, saved themes, 760px Settings and the 424px quick dashboard. All 75 browser UI checks passed; Linux passed 177 Rust tests with five existing ignored tests and three isolated credential checks. Windows/Linux release CLI, actual installer checks and all three package jobs also passed. Final-version CI and the tagged release separately gate publication on the three platform packages, complete checksums and signed updater feed.

Tests use isolated synthetic accounts. Hosted native-window checks do not establish physical tray clicks, taskbar appearance, Wayland, additional monitors, login startup or real Google authorization/account switching. Native Mac menu account badges were not independently captured by the UI tool; identity detection and menu projection have separate regression coverage. A saved selection is not proof of live credentials, and missing/stale quotas remain unknown. The fixes do not establish why an earlier live login changed when no initiating switch was retained in logs.

Packages have no Apple Developer ID/notarization or Windows Authenticode certificate. A complete ad-hoc bundle signature and signed updater feed do not establish OS trust. Eligible apps can discover this stable release through startup/manual checks; installation requires user action. Mac installations that fail system trust checks use the release page for manual installation. Homebrew does not bypass those checks. See [updates](../software-updates.md), [Homebrew](../homebrew.md), [Windows](../windows.md) and [Linux](../linux.md).

本次使用隔离的合成账号验证，没有通过操作真实账号来测试切换。Windows/Linux 原生测试在托管系统运行，物理托盘点击、Wayland、多显示器和开机登录仍未实测。当前 Mac 安装包仍无 Apple 开发者签名和公证，Windows 安装包无 Authenticode 签名；更新检查会提示可用版本，安装仍需用户操作，Homebrew 不会绕过系统信任检查。
