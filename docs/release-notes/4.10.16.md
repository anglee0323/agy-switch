## 本次更新

- 支持 Google 新发布的 Gemini 4 Carbon、Gemini 4 Hydrogen（含 Extra/xhigh 档位）以及 Orchestrator (Carbon)、Orchestrator (Argon)。新模型会按档位归并到对应主模型，不再显示成未知名称或错误并入旧系列。
- 支持 Claude Sonnet 5.5 与 Claude Opus 5.5。Claude 5.5 的 Low/Medium/High 档位和 thinking 名称会归并到 5.5，不再被折叠成 4.6；已保存的 4.6 记录仍可正常显示。
- 更新 Gemini 与 Claude 计价：Gemini 4 Carbon、Gemini 4 Hydrogen 使用官方标准价，Carbon/Argon 在 2026-12-01 的调价按当前日期选择生效价格；Carbon/Hydrogen 的 `-low`、`-medium`、`-high`、`-xhigh` 档位和 Claude 5.5 的档位按同一模型单价估算，不再显示为未计价。
- 计价页地址改为 Google 当前发布的 `aistudio.google.com/docs/pricing.md.txt`，并提升解析器版本以丢弃旧缓存。内置兜底价目表补充 Gemini 4 Carbon、Gemini 4 Hydrogen，并保留 Carbon/Argon 的当前档位价。
- 识别 Gemini 4 Carbon 独立配额：当接口返回 `gemini-carbon-5h` / `gemini-carbon-wtu-weekly` 时，Carbon 不再借用共享 Gemini 额度；仪表盘新增 Carbon 周额度均值，账号卡片、账号表和周期变化中也会显示 Carbon 桶。接口未返回 Carbon 桶时保留模型自身的观测值，不虚构额度。
- 默认置顶模型更新为 Gemini 3.1 Pro、Gemini 3.8 Flash、Claude Sonnet 5.5；已保存的自定义置顶不受影响。
- 兼容 Antigravity 2.32 / CLI 1.5.x 的模型目录变化：`agy --hub` 后端、Claude 4.6 与 GPT-OSS 的下线转发继续沿用现有处理，不需要修改账号或切换流程。

## Changes

- Adds Gemini 4 Carbon, Gemini 4 Hydrogen (including the Extra/xhigh effort), Orchestrator (Carbon) and Orchestrator (Argon). Effort tiers fold into their canonical model instead of appearing as unknown names or collapsing into an older family.
- Adds Claude Sonnet 5.5 and Claude Opus 5.5. Their Low/Medium/High tiers and thinking names stay on 5.5 instead of collapsing into 4.6; saved 4.6 records remain displayable.
- Updates Gemini and Claude pricing: Gemini 4 Carbon and Hydrogen use the published standard rates, Carbon/Argon's 2026-12-01 cutover is selected by the current date, and Carbon/Hydrogen effort tiers plus Claude 5.5 tiers estimate the same model's rates instead of appearing unpriced.
- Moves the pricing source to Google's current `aistudio.google.com/docs/pricing.md.txt` URL and bumps the parser revision so older caches are discarded. The built-in fallback now includes Gemini 4 Carbon and Hydrogen and keeps the current Carbon/Argon introductory rates.
- Recognizes Gemini 4 Carbon's dedicated quota. When the API reports `gemini-carbon-5h` / `gemini-carbon-wtu-weekly`, Carbon no longer borrows shared Gemini headroom; the dashboard gains a Carbon weekly mean, and account cards, the account table and cycle details show Carbon buckets. When no Carbon bucket is reported, the model's own observation is retained instead of inventing an allowance.
- Updates the default pinned models to Gemini 3.1 Pro, Gemini 3.8 Flash and Claude Sonnet 5.5. Existing custom pins are preserved.
- Keeps the existing Antigravity 2.32 / CLI 1.5.x compatibility: the `agy --hub` backend and the Claude 4.6 / GPT-OSS retirement forwarding continue to use the existing account and switching paths.

## Verification and limits

The Gemini and Claude pricing pages were fetched on 2026-11-15. The Gemini page parsed 31 models, including `gemini-4-carbon` at $2.00 input / $10.00 output / $0.10 cached per 1M tokens through 2026-11-30 ($4.00 / $20.00 / $0.20 from 2026-12-01) and `gemini-4-hydrogen` at $1.50 / $7.50 / $0.075. The Claude page parsed the 5.5 rows at $4 / $20 / $0.20 (Opus) and $2 / $10 / $0.10 (Sonnet).

Rust unit tests (257 passed, 4 ignored), the shared pricing/catalog fixtures, the mocked UI suite and the three platform package jobs are the verification for this change. No real account was switched, refreshed, exported or deleted. Live Antigravity entitlement, a real Carbon quota bucket and the native tray layout were not exercised with a signed-in account; the Carbon pool path is covered by synthetic observations. Mac packages still lack Developer ID/notarization and Windows packages lack Authenticode; bundle and updater signatures do not establish OS trust. Installation requires user action; see [updates](../software-updates.md).
