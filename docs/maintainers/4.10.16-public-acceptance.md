The [PR checks](https://github.com/anglee0323/agy-switch/pull/136) (three-platform package jobs, CLI jobs and complete-set verification), the main Build/Release CLI runs at the frozen source, and the [formal release workflow](https://github.com/anglee0323/agy-switch/actions/runs/43714143757) all passed, including complete-set validation and publication.

The public Mac ZIP, extracted in an owned temporary directory, contains an arm64
`AntiGravity Switch.app` whose `agy-switch-desktop` and bundled `agy-switch` both
report `agy-switch 4.10.16`; `codesign --verify --deep --strict` accepts the complete
ad-hoc bundle signature. The Linux deb reports package `agy-switch` 4.10.16 for
`amd64` with the expected WebKitGTK/GTK dependencies and ships an x86-64 ELF console
executable. The Windows console ZIP contains an x64 PE console executable; the
installer is an NSIS self-extracting executable. Gatekeeper acceptance and
notarization were not tested.

The generated Homebrew recipe was regenerated from the downloaded public ZIP and is
byte-identical to the release workflow's artifact; its pinned SHA-256 matches the
public archive.

Not performed for this release: Windows/Linux package installation on native hosts,
macOS GUI launch of the installed bundle, a live account switch or quota refresh, a
live Gemini 4 Carbon quota observation, and fresh Homebrew installation, upgrade,
custom app directory and uninstall. Mac packages lack Developer ID/notarization and
Windows packages lack Authenticode; bundle and updater signatures do not establish
OS trust. Live Google login and physical Windows/Linux tray behavior remain separate
acceptance.
