The [PR checks](https://github.com/anglee0323/agy-switch/pull/141) (three-platform package jobs, CLI jobs and complete-set verification), the main Build/Release CLI runs at the frozen source, and the [formal release workflow](https://github.com/anglee0323/agy-switch/actions/runs/43842252874) all passed, including complete-set validation and publication.

The public Mac ZIP, extracted in an owned temporary directory, contains an arm64
`AntiGravity Switch.app` whose `CFBundleShortVersionString` is 4.10.17 and whose
`agy-switch-desktop` and bundled `agy-switch` both report `agy-switch 4.10.17`;
`codesign --verify --deep --strict` accepts the complete ad-hoc bundle signature and
the executable's minimum macOS version is 11.0. The Linux deb reports package
`agy-switch` 4.10.17 for `amd64` with `xdg-utils`, `libayatana-appindicator3-1`,
`libwebkit2gtk-4.1-0` and `libgtk-3-0` dependencies. The Windows console ZIP contains
an x64 PE console executable; the installer is an NSIS self-extracting executable.
Gatekeeper acceptance and notarization were not tested.

The generated Homebrew recipe was regenerated from the downloaded public ZIP with
`scripts/generate-homebrew.mjs`; its pinned SHA-256 matches the public archive and it
is the file committed at `Casks/agy-switch.rb`.

The quota changes are covered by the Rust unit tests, the shared quota fixtures, the
mocked UI suite and the contributor's live Windows 11 refresh with real accounts.
No real account was switched, refreshed, exported or deleted during maintainer
verification.

Not performed for this release: Windows/Linux package installation on native hosts,
macOS GUI launch of the installed bundle, a live account switch or quota refresh on
this machine, a live Gemini 4 Argon quota observation, and fresh Homebrew
installation, upgrade, custom app directory and uninstall. Mac packages lack
Developer ID/notarization and Windows packages lack Authenticode; bundle and updater
signatures do not establish OS trust. Live Google login and physical Windows/Linux
tray behavior remain separate acceptance.
