prerelease and is the latest stable release. The published body contains the reviewed

The [PR checks](https://github.com/anglee0323/agy-switch/pull/144) (three-platform package
jobs, CLI jobs and complete-set verification), the main Build/Release CLI runs at the frozen
source, and the [formal release workflow](https://github.com/anglee0323/agy-switch/actions/runs/44322190418)
all passed, including complete-set validation and publication. The first two release attempts
were not acquired by a hosted macOS arm64 runner within the queue window; nothing had been
staged as a draft and nothing was published, and the successful rerun rebuilt every package
before the complete set was verified and published.

The public Mac ZIP, extracted in an owned temporary directory, contains an arm64
`AntiGravity Switch.app` whose `CFBundleShortVersionString` is 4.10.18 and whose
`agy-switch-desktop` and bundled `agy-switch` both report `agy-switch 4.10.18`;
`codesign --verify --deep --strict` accepts the complete ad-hoc bundle signature and
the executable's minimum macOS version is 11.0. With an isolated synthetic data directory,
the bundled CLI answered `--version`, `--help`, `accounts list --json`, `policy show --json`
and returned exit code 3 for `quota` on an empty store. The Linux deb reports package
`agy-switch` 4.10.18 for `amd64` with `xdg-utils`, `libayatana-appindicator3-1`,
`libwebkit2gtk-4.1-0` and `libgtk-3-0` dependencies, matching the workflow's installed-package
test. The Windows console ZIP contains an x64 PE console executable; the installer is an
NSIS self-extracting executable. Gatekeeper acceptance and notarization were not tested.

The generated Homebrew recipe was regenerated from the downloaded public ZIP with
`scripts/generate-homebrew.mjs`; its pinned SHA-256 matches the public archive and it
is the file committed at `Casks/agy-switch.rb`.

The account-remark write race is covered by the Rust unit tests through the shared typed
save path; interactive remark editing in the packaged GUI was not separately re-run against
a signed-in client. No real account was switched, refreshed, exported or deleted during
maintainer verification.

Not performed for this release: Windows/Linux package installation on native hosts,
macOS GUI launch of the installed bundle, a live account switch or quota refresh on
this machine, and fresh Homebrew installation, upgrade, custom app directory and
uninstall. Mac packages lack Developer ID/notarization and Windows packages lack
Authenticode; bundle and updater signatures do not establish OS trust. Live Google
login and physical Windows/Linux tray behavior remain separate acceptance.
