The [PR checks](https://github.com/anglee0323/agy-switch/pull/127) (three-platform package jobs, optimized CLI jobs and complete-set verification), the main Build/Release CLI runs at the frozen source, and the [formal release workflow](https://github.com/anglee0323/agy-switch/actions/runs/41429610048) all passed, including complete-set validation and publication. One PR macOS test job was cancelled after waiting 15 minutes without a runner; its rerun passed.

The public Mac ZIP, extracted in an owned temporary directory, passes
`scripts/verify-macos-bundle.mjs` (version 4.10.14, ARM64, complete ad-hoc bundle
signature, empty entitlements; no team identifier) with a macOS 11.0 deployment target.
Its bundled console passed 45 CLI smoke checks and 68 real PTY checks against synthetic
data directories. The Linux deb reports package `agy-switch` 4.10.14 for `amd64`; the
Windows console ZIP contains an x64 PE console executable. Gatekeeper acceptance and
notarization were not tested. With an isolated data directory, the public 4.10.13 console
reports v4.10.14 as an available update and the new console reports it is current.

The maintainer's installed App was replaced directly with this public ZIP. The installed
bundle is byte-identical to the verified extraction and passes strict signature checks;
both `agy-switch` links report 4.10.14, the LaunchAgent still points to the installed
executable, and saved preference hashes were unchanged before and after launch.

Not performed for this release: Windows/Linux package installation on native hosts,
live IDE 2.6 switching, a signed-in Windows switch, and fresh Homebrew installation,
upgrade, custom app directory and uninstall. Mac packages lack Developer ID/notarization
and Windows packages lack Authenticode; bundle and updater signatures do not establish
OS trust. Live Google login and physical Windows/Linux tray behavior remain separate
acceptance.

The generated Homebrew recipe pins the public ZIP hash above; its required recipe check
fetches that archive and regenerates the recipe before merge.
