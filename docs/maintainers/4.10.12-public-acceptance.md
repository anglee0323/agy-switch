The [PR checks](https://github.com/anglee0323/agy-switch/pull/113) (three-platform package jobs, optimized CLI jobs and complete-set verification), the main Build/Release CLI runs at the frozen source, and the [formal release workflow](https://github.com/anglee0323/agy-switch/actions/runs/41188885226) all passed, including complete-set validation and publication.

The public Mac ZIP, extracted in an owned temporary directory, passes the strict
complete resource-signature, ARM64/version and empty-entitlement checks, and its
bundled console passed 45 isolated CLI checks. Gatekeeper acceptance and
notarization were not tested. The same source was previously built locally with an
equivalent ad-hoc recipe and installed over the maintainer's App for review; the
public ZIP itself was not installed.

Not performed for this release: Windows/Linux package installation on native
hosts, PTY/ConPTY terminal runs and 40-account viewport checks against the public
assets, update-discovery from 4.10.11, and fresh Homebrew installation, upgrade,
custom app directory and uninstall. The native macOS menu layout was reviewed by
the maintainer on the locally installed build, not captured in an automated
screenshot. Mac packages lack Developer ID/notarization and Windows packages
lack Authenticode; bundle and updater signatures do not establish OS trust.
Live Google login, authenticated switching and physical Windows/Linux tray
behavior remain separate acceptance.

The generated Homebrew recipe pins the public ZIP hash above; its required recipe
check fetches that archive and regenerates the recipe before merge.
