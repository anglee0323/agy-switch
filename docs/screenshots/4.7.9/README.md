# Screenshot sources

These are real Tauri/WebKitGTK viewports from the integrated 4.7.9 CI debug build, source and checkout commit [`5be961d3149be5f80bdd4b39b51b4a4020dea4cd`](https://github.com/anglee0323/agy-switch/commit/5be961d3149be5f80bdd4b39b51b4a4020dea4cd). They are not screenshots of an installed release package.

The [native Linux artifact](https://github.com/anglee0323/agy-switch/actions/runs/37233892799/artifacts/11314469250) passed six viewport captures, real IPC, theme persistence, narrow layout and process cleanup checks. Four selected images were visually inspected and copied unchanged; [provenance.json](provenance.json) records their dimensions and hashes. They use English, synthetic accounts and empty usage records, and exclude the system window frame. Settings content below the 1024 × 700 viewport requires scrolling.

Windows native GUI acceptance at the same source remains blocked before launch by the hosted WebView2/Wry environment; no Windows screenshots or GUI pass are claimed. Native Mac menu appearance is reviewed separately and is not represented by these Linux images.
