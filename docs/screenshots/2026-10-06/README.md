# Screenshot sources / 截图来源

These screenshots were supplied by the project owner on 6 October 2026 (Asia/Shanghai). They show the local macOS 4.9.0 application, console and native menu bar, including local branding refinements. Original PNGs are copied without cropping, resizing or retouching. Some email regions were obscured by the owner in the supplied images. Account remarks are user-entered text and are not translated when the interface language changes.

截图由项目作者于 2026 年 10 月 6 日提供，展示本地 macOS 4.9.0 应用、命令行和原生菜单栏，包含本地品牌显示调整。原始 PNG 直接复制，未裁剪、缩放或修图。作者已在部分邮箱区域作了遮挡；账号备注属于用户输入，不随界面语言翻译。

The two menu bar screenshots use temporary example usage and quota data (3.384 million tokens, 186 requests, an estimated $2.85 and four accounts with varied quotas). These values demonstrate the layout and do not represent actual usage, balances or billing. Other views show the local application as captured. The later Chinese dashboard capture completes the Chinese set.
